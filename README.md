# SilverGuard
A Chrome Web Extension for seniors to be alerted of malicious material currently on their screen. 

# Getting Started & Development Setup

Because SilverGuard requires a backend database to store scan statistics and a cloud function to securely process Gemini API requests, you will need to set up your own Firebase environment to run this project locally.

## Prerequisites
* [Node.js](https://nodejs.org/) installed
* A free [Firebase / Google Cloud Account](https://console.firebase.google.com/)
* A free [Google Gemini API Key](https://aistudio.google.com/app/apikey)

## Setting up the Core Extension
Follow these steps to get the backend running and the Chrome extension working on your machine.

### Step 1: Clone & Install Backend
First, clone the repository and install the dependencies required for the Firebase Cloud Functions.

```bash
git clone [https://github.com/YOUR-USERNAME/SilverGuard.git](https://github.com/YOUR-USERNAME/SilverGuard.git)
cd SilverGuard/functions
npm install
```

### Step 2: Firebase Project Setup
You need a database to store user statistics securely and host the backend.

1. Go to the [Firebase Console](https://console.firebase.google.com/) and create a new project.
2. In the left menu, click **Firestore Database** and click **Create Database**. Leave the database ID as `(default)`.
3. In the left menu, click **Authentication**, go to **Sign-in method**, and enable **Google**.
4. Upgrade your Firebase project to the **Blaze (Pay as you go)** plan. *(Note: Cloud Functions require this plan to deploy, but standard Gemini API calls and low-traffic usage easily fall within the free tier).*

### Step 3: Deploy the Backend
Provide the backend with your Gemini API key and deploy it to the cloud.

1. Install the Firebase CLI globally: `npm install -g firebase-tools`
2. Log in to your account: `firebase login`
3. Initialize the project: `firebase use --add` (Select the project you just created).
4. Save your Gemini API key securely:
    ```bash
    firebase functions:secrets:set GEMINI_API_KEY
    # Paste your key when prompted and press Enter
    ```
5. Deploy the function:
    ```bash
    firebase deploy --only functions
    ```
    *(Once deployed, the terminal will output a **Function URL**. Copy this URL!)*

### Step 4: Configure Google Authentication (OAuth)
Because the extension uses Google Sign-In, you must generate a unique OAuth Client ID so Google recognizes your local extension.

1. First, load the extension into Chrome:
   * Open Chrome and navigate to `chrome://extensions/`
   * Toggle **Developer mode** (top right corner).
   * Click **Load unpacked** and select the root folder of this repository.
2. Copy the **Extension ID** (a long string of letters) generated by Chrome on that page.
3. Go to the [Google Cloud Console](https://console.cloud.google.com/) and select the Firebase project you created in Step 2.
4. Navigate to **APIs & Services** > **Credentials**.
5. Click **+ Create Credentials** > **OAuth client ID**.
6. Set the Application type to **Chrome app** and paste your **Extension ID** into the Application ID field. Click Create.
7. Copy the generated **Client ID**.
8. Open the `manifest.json` file in your code editor and replace the existing placeholder with your new Client ID:
   ```json
   "oauth2": {
     "client_id": "YOUR_NEW_CLIENT_ID_HERE",
     "scopes": ["email", "profile"]
   }
   ```
 
### Step 5: Connect & Load the Extension
1. Open the extension's `popup.js` file and replace the `backendUrl` variable with the Function URL you just copied.
2. Go back to chrome://extensions/, find the SilverGuard extension, and click the Refresh icon (the circular arrow) to apply your changes.
